# dsh-nocturne 0.4 现行需求基线

本文是当前版本的验收边界。design-plan.zh.md 是 v1 决策留痕，不再作为现行完成度清单。

## 已实现

| 需求 | 当前契约 | 自动验证 |
| --- | --- | --- |
| 纸与房间 | 6 张纸 × 3 个房间，18 种正交组合 | Edge 离线遍历 18 组合 |
| 纸张渲染 | WebGL2 surface/light 双 pass，DOM 文字保持原生 | 生成包、GPU 恢复、无 WebGL 用例 |
| 无 WebGL 降级 | 保留静态纸色，不阻断输入和界面 | 禁用 WebGL 的浏览器用例 |
| 光标 | 墨迹 / 羽毛 / 原生；IME 与非折叠选区让位 | 模块与真实 DSH 人工回归 |
| 滚动条 | 纸夹 / 细杆 / 原生；保留原生滚动 | 内容增长与几何刷新用例 |
| 设置 | Studio 与控制台 API 共用更新、校验和持久化管线 | 单元、API 浏览器用例 |
| 桌面持久化 | 回环宿主接口 + 本地缓存，文档 schema 校验 | 真实 HTTP 读写用例 |
| 皮肤共存 | full 才改宿主色；material 不写宿主 alias/specific | 单元与浏览器用例 |
| 卸载 | 移除监听、画布和自有 DOM，恢复挂载前内联样式 | 样式所有权与卸载用例 |
| 低动态 | 颗粒与装饰尘埃停止动画，滚动保留可用性 | reduced-motion 浏览器用例 |
| 诊断 | 默认轻量；显式开启后才扫描 DOM 和自动采样 GPU | 单元与帧异常断言 |

## 明确不做或延期

- Three.js 拟物打字机、敲击音效、拉绳开关：不做。
- 墨滴化开的自定义选区：已否决，保留系统选区行为，只改颜色。
- v1 中的蜡封、落字动画和终端 ANSI：未进入当前版本；如需恢复，先另立需求和验收标准。
- 独立原生设置页已在 0.5 落地，旧上游悬浮 Studio 不再用于插件。
- 本轮不重做 DSH 的信息架构、会话数据流或输入语义。

## 发布前仍需真机确认

自动化桩页不能替代完整 DSH：安装重启、长会话流式输出、IME 中文输入、与其他皮肤的真实组合、显卡驱动重置和 DSH 升级，均列入发布前人工回归。
